## 1. Executive summary

Claude Sonnet 5 is Anthropic's speed/intelligence balance tier: a 1M-token
context window and 128k max output at $2/$10 per million input/output tokens —
**until 2026-08-31**, after which the same model costs $3/$15.

That expiry is the single most decision-relevant fact on this page. It is 28 days
away as of capture, and it is a **50% increase on both input and output**. Any
cost comparison, budget plan, or stack recommendation built on the current price
breaks on 1 September. The Atlas models this as two facts with adjacent validity
intervals rather than one fact that will silently become wrong
([TEMPORAL.md](../../../TEMPORAL.md) §2).

The second notable fact is a documentation ambiguity we could not resolve:
whether Sonnet 5 uses Anthropic's newer tokenizer, which produces **~30% more
tokens for the same text**. If it does, the effective price increase relative to
older-tokenizer models is larger than the headline number suggests — a bigger
effect than the entire introductory discount. See §13.

## 3. Current status

Active and generally available on the Claude API. Model ID `claude-sonnet-5` is
a **pinned snapshot**, not an evergreen pointer — Anthropic documents that from
the 4.6 generation onward, dateless IDs are still fixed to a specific release.
That matters for reproducibility: a measurement taken against `claude-sonnet-5`
today refers to the same weights as one taken next month, which is *not* safe to
assume with every vendor.

**The 1M context window is priced flat.** A 900k-token request bills at the same
per-token rate as a 9k-token request — no long-context tier premium. This is a
genuine structural difference from providers that tier long-context pricing, and
it changes how you should architect agent context: there is no price cliff to
design around.

## 5. Limitations

- **Extended thinking via `thinking.type: "enabled"` is not available.** Code
  written against that parameter for earlier models does not carry over; adaptive
  thinking is the replacement.
- **Tool use carries a fixed per-request tax.** 354 tokens with `auto`/`none`,
  474 with `any`/`tool`, on *every* call. At high request volume with small
  payloads this is a real fraction of input cost, and it is invisible in a
  per-million-token price comparison.
- **Pricing increases 50% on 2026-09-01.** Not a limitation of the model, but the
  most likely reason a plan built around it fails.
- **No independent verification of any capability above.** All of §4 is vendor
  self-description.

| | Input | 5m cache write | 1h cache write | Cache hit | Output |
|---|---|---|---|---|---|
| Standard | $3.00 | $3.75 | $6.00 | $0.30 | $15.00 |
| Batch (−50%) | $1.50 | — | — | — | $7.50 |

All figures per million tokens, USD, `pricing_as_of: 2026-08-03`.

**Modifiers that stack:** batch −50% · US-only `inference_geo` ×1.1 · regional
or multi-region cloud endpoints +10%.

**Cache economics.** A cache hit costs 0.1× base input. Anthropic states the
5-minute cache (1.25× write) pays for itself after **one** read, and the 1-hour
cache (2× write) after **two**. For agentic work that re-sends a stable system
prompt and repository context every turn, this is usually the largest single
cost lever available — larger than choosing a cheaper model.

## 13. Known unknowns

**RG-001 — Does Sonnet 5 use the newer tokenizer?** *(highest-impact unknown)*

Anthropic's pricing page states the ~30%-more-tokens tokenizer applies to
"Claude 4.7 and later models", and names "Claude Sonnet 4.6 and earlier" as using
the previous one. The models overview attaches the tokenizer tooltip explicitly
to Claude Fable 5. Sonnet 5 is not named either way.

Why it matters more than it sounds: if Sonnet 5 inflates tokens ~30%, its
effective cost is ~30% higher than its posted price implies **when compared
against older-tokenizer models**. That is a larger effect than the entire
introductory discount, and it silently corrupts any cross-model per-token price
comparison. Recorded as a `conflicts` block with `likely_cause: unexplained`
rather than resolved by inference.

**Also unknown:** introductory-pricing start date · release date · rate limits ·
real-world reliability · behaviour at the top of the 1M window · whether adaptive
thinking materially changes output-token consumption (it would change cost, and
output is the expensive side).
